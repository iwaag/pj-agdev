# this is
人間の創造欲求を引き出し、その欲求を実現するシステム。

# submodules

## agdevworld

映像と音声の入出力で開発体験を提供する没入型開発インターフェイス。
同時にプライムエージェントのワークスペースを兼ねる。プライムエージェントはユーザーと直接対話をして要望を受けたり情報を提供し、裏ではclusterintentやagforgeなどのエージェントとやり取りをしてユーザー願望の実現を目指す。
操作はプライムエージェントのへの言葉での指示が主、クリックやキーボード操作は補助。

## agforge

画像、音楽、映像といったアセットの生成を行うエージェントのワークスペース。
Easier Next Timeのポリシーに沿ってノウハウや設定ファイル、ドキュメント、スクリプトなどを蓄積していく。
