# this is
人間の創造欲求を引き出し、その欲求を実現するシステム。

# submodules

## agdevworld

映像と音声の入出力で開発体験を提供する没入型開発インターフェイス
pj-clusterintentが開発環境であるクラスターの情報を提供する前提で、その状態を可視化したり操作できるようにする。
操作はエージェントのへの言葉での指示が主、クリックやキーボード操作は補助。

## agforge

画像、音楽、映像といったアセットの生成を行うエージェントのワークスペース。Easier Next Timeのポリシーに沿ってノウハウや設定ファイル、ドキュメント、スクリプトなどを蓄積していく。
