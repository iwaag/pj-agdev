# 自動化アイディア集（人間の手動操作なしでできそうなこと）

前提: `auto_capable.md` の機能のみ使用。確信度は「できるかも」レベルを含む。
音声の取り出しは scope2 の AudioCache 抽出パス（非公式・1リクエスト直列）に依存する。

## 歌声生成系

1. **歌詞→ジングル自動生成サービス（既に実証済みの拡張）**
   agforge に「この歌詞で10秒のジングル」と投げると、メロディ生成（LLM作曲）→
   ノート打ち込み→合成→WAV→URL返却まで全自動。scope2 の E2E をテンプレ化して
   定型サービスに昇格させる。

2. **バリエーション一括生成（A/Bテスト工場)**
   同じ歌詞に対しメロディ・テンポ・キーを変えた候補を N 個直列生成し、
   RMS・ピッチレンジ等の機械指標付きで一覧提示。人間は最後に聴いて選ぶだけ。
   ※直列必須なので N は小さめが現実的。

3. **歌手オーディション自動化**
   同一メロディ+歌詞を `sound-source list` の全歌手（タグで絞り込み）で
   順に歌わせ、聴き比べ用 WAV セットを自動生成。「Pop×Female×Bright の
   歌手全員でこのサビを」みたいな依頼が一発になる。

4. **通知・システム音声の「歌うボイス」化**
   ビルド成功/失敗、デプロイ完了などを短い歌にして生成し、通知音として配布。
   agautolab の完了通知が歌で届く、という遊び。

5. **日替わりテーマソング bot**
   スケジュール実行で「今日の日付・天気・予定」から短い歌詞を作り、
   毎朝1曲生成して置いておく。

6. **ゲーム用ボーカルアセットのバッチ生産**
   agdevworld 用の掛け声・短いフレーズ（「レベルアップ！」等）をリスト化し、
   夜間に順次生成してアセットフォルダに蓄積。

## カタログ・ライブラリ系

7. **コミュニティボイス・スカウト**
   `community-list` を全ページ巡回して名前・タグ・言語のカタログ DB を作成。
   条件に合う新着ボイスを定期チェックして報告。`community-collect` まで
   自動化するかは要検討（アカウント副作用があるので提案止まりが無難）。

8. **手持ち音源の棚卸しレポート**
   歌手・楽器・アンサンブルの全リストとタグ分布を Markdown レポート化。
   「日本語が歌える歌手一覧」などの参照資料を自動生成・更新。

## プロジェクト操作・解析系

9. **プロジェクトの構造ダンプ / 疑似バックアップ**
   トラック・クリップ・ノート・歌詞・テンポ・拍子を全部読み出して JSON 化。
   保存コマンドは無いが「ノートデータのスナップショット」として復元材料になる
   （復元も add-notes で機械的に再打ち込み可能なはず）。

10. **プロジェクト間コピー / トランスポーズ職人**
    読み出したノートを ±N 半音シフトして別クリップに再打ち込み。
    キー違いバージョンやハモリ（3度上トラック）の自動生成。
    ※Sing クリップは単音制約なのでハモリは別トラックに。

11. **テンポマップ・ジェネレータ**
    「サビで +4BPM、アウトロで ritardando」のような指示を tempo set の
    ポイント列に変換。揺らぎ（humanize）カーブの自動付与も。

12. **歌詞差し替えリテイク**
    既存メロディを維持したまま歌詞だけ差し替えて再合成。CM の
    「地名だけ差し替え」的な量産に向く。かな分解＋モーラ割当は
    エージェント側で確実にやる（sentence モードは信用しない）。

## 品質・運用系

13. **自動 QA ループ**
    生成 WAV を毎回 RMS / 無音率 / クリッピングで検査し、閾値割れなら
    自動リトライまたは problem 報告。scope2 の検証手順をルーチン化。

14. **サーフェス昇格ウォッチャー**
    定期 cron で `acestudio-cli --version` を確認し、surface が 1.0 から
    動いたら `--print-paths` 差分を取って報告。export / generative 系が
    公開された瞬間に検知できる（report.md の推奨事項の実装）。

15. **合成待ちオーケストレータ**
    `status synthesis` ポーリング + marker/loop 制御を共通ヘルパー化し、
    「区間を合成→再生→キャプチャ」を1関数にする（scope2 推奨の
    キャッシュ処理ヘルパーと合わせて）。

## 外部連携系（ACE Studio 外の処理と組み合わせ）

16. **ボーカル＋伴奏の自動ミックス**
    ACE Studio でボーカル、scope1 の ACE-Step LAN サービスで伴奏を生成し、
    ffmpeg で外部ミックスして1曲に。ACE Studio 内ミックスは export 不可なので
    外で混ぜるのが現実解。

17. **MIDI 風データからの打ち込み代行**
    外部で作った旋律データ（LLM 生成、アルゴリズム作曲、既存の楽譜データ）を
    add-notes 形式に変換して流し込む汎用インポータ。import コマンド不在の代替。
